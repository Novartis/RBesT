# Transplant.

Data set containing historical information for standard treatment for a
phase IV trial in de novo transplant patients. The primary outcome is
treament failure (binary).

## Usage

``` r
transplant
```

## Format

A data frame with 4 rows and 3 variables:

- study:

  study

- n:

  study size

- r:

  number of events
